Archivio permanente del Personal AI Research & Intelligence Hub (Finance, Tech, Luxury: M&A e financing).

- **Dashboard:** https://claude.ai/artifact/4jnCXTGpqJQfVmyLZnkrao (privata)
- **Manuale operativo per Claude:** [CLAUDE.md](CLAUDE.md)
- **Profilo e linea editoriale:** [config/profile.md](config/profile.md) · **Fonti:** [config/sources.md](config/sources.md)

| Cartella | Contenuto |
|---|---|
| `daily/` | Daily Intelligence di ogni esecuzione |
| `focus/` | Dossier dei Focus (`_index.json` = elenco) |
| `knowledge/entries/AAAA/MM/` | Una voce per informazione, con stato e fonte; `changelog.md` registra i cambiamenti |
| `library/` | `inbox/` per documenti caricati via Git, `notes/` per le analisi |
| `linkedin/` | Bozze; lo stato (bozza, approvato, pubblicato) è gestito nella dashboard |
| `insights/` | Proposte di nuovi Focus, connessioni, domande |
| `data/runs/` | Dati grezzi di ogni esecuzione (JSON) |
| `scripts/render.py` | Genera Markdown e documenti per la dashboard da un file di esecuzione |
